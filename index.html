FEATURED PROJECT · DATASET DEVELOPMENT

Maharashtra Livestock
Diversity Dataset

IN PROGRESS

A structured district-level view of livestock diversity in Maharashtra, built around a simple principle: a dataset is only useful when its definitions, sources and limitations are clear.

THE PROBLEM

Livestock figures come from different statistical products and reference years. Combining them without preserving their source type can create misleading comparisons.

MY APPROACH

Clean district names, standardise indicator labels, retain source metadata and distinguish census observations from survey estimates and modelled values.

DATA SOURCES

20th Livestock Census (2019) and official animal-husbandry statistical publications. Annual estimates are treated separately from census counts.

TOOLS & METHODS

Python and spreadsheet-based inspection, CSV data cleaning, validation checks, metadata documentation and district-level reconciliation.

FEATURED CASE STUDY · IN PROGRESS

Maharashtra Livestock Diversity Dataset

A district-level dataset project focused on making livestock statistics more consistent, traceable and understandable.

Problem

Livestock statistics are published across different statistical products and reference years. Mixing them without retaining definitions and source types can lead to misleading comparisons.

Data sources

20th Livestock Census (2019) and official animal-husbandry statistical publications. Census observations, state survey estimates and modelled values are kept distinguishable.

Method

District-name cleaning and reconciliation, indicator standardisation, source metadata retention, validation checks and documentation of limitations.

Tools

Python, spreadsheets and CSV-based data inspection and cleaning workflows.

Current outcome

The work is in progress. The focus is a documented, auditable dataset structure; verified analysis outputs will be added as they are ready.
